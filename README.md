# Cast & Render

This project is a static landing page built in a single HTML file and is ready to deploy to Vercel.

## Files

- `index.html` — the website
- `vercel.json` — Vercel static hosting configuration
- `.gitignore` — standard ignore rules

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Open https://vercel.com and import the repo.
3. Select the default project settings.
4. Vercel will detect it as a static site and deploy it.

## Local preview

```bash
python -m http.server 8000
```

Then open http://localhost:8000
